# Домашнее задание к лекции 2. «Iterators. Generators. Yield»

## Описание

Проект содержит решения четырёх заданий:

1. **FlatIterator** — итератор для плоского обхода списка списков.
2. **flat_generator** — генератор для плоского обхода списка списков.
3. **FlatIteratorRecursive** — итератор для списков с любой вложенностью (необязательно).
4. **flat_generator_recursive** — генератор для списков с любой вложенностью (необязательно).
