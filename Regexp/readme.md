# Домашнее задание к лекции «Регулярные выражения»

## Описание

Проект содержит функции для валидации данных с помощью регулярных выражений:

- `is_valid_ipv4` — проверка IPv4-адреса.
- `is_valid_phone` — проверка российского номера телефона.
- `is_balanced` — проверка сбалансированности скобок.

## Установка и запуск

```bash
python main.py
