# Домашнее задание 1. «Import. Module. Package»

## Структура проекта

- `main.py` — основной модуль для запуска программы.
- `application/salary.py` — модуль с функцией `calculate_salary`.
- `application/db/people.py` — модуль с функцией `get_employees`.
- `dirty_main.py` — демонстрация импорта через `*` (необязательное задание).
- `requirements.txt` — зависимости проекта.

## Запуск

```bash
python main.py
